# Token Circles product copy review

September 30, 2026. The owner requested a shared writing rule for Codex and Claude, then a copy pass on this native-app presentation. The first batch covers stock AI wording and vague sales promises. This does not approve a visual composition, native feature scope or billing choice.

The canonical rule is [product-voice](/home/maff/.dotfiles/personal/agentic/skills/product-voice/SKILL.md). Both tools' personal skill directories link to the same folder, and their global instructions load it for user-facing writing. New sessions will pick up that standing instruction; existing sessions need to read the updated file.

## The rule in practice

Use words that describe what someone can do, see or understand. Give welcome copy character through a specific idea. Keep buttons, error messages and payment choices precise. Remove unsupported mood claims and generic sales promises, and preserve facts, numbers and meaningful uncertainty.

The owner's explicit mood-word ban covers _calm, calmer, calmest, calming_ and _calmly_ in product copy. The broader approved batch removes vague uses of _seamless, effortless, intuitive, delightful, elevate, empower, unlock, journey, reimagine_ and _curated_. Literal uses, quotations and code retain their meaning. Newly authored visible English copy avoids em dashes, following the existing cross-product preference.

The preference register lists further candidates for later review. An automatic word search is a useful reminder; it cannot judge the whole sentence or guarantee good writing.
